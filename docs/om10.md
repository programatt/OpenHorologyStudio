# Tutorial: an OM10 modification study

This walks through a complete study on the open-source
[openmovement OM10](https://openmovement.org/) using only OHS and its lessons: read the movement,
see how it keeps time, change one thing, check that it still works and can be made.

!!! warning "About the numbers"
    The OM10 files are not in this repository. Where numbers appear below they come from OHS's
    built-in demo movement so you can see the shape of each result; yours will differ. The
    calibre parameters are typical values, not OM10's measured ones, until you calibrate them.

## 0. Get the movement

openmovement serves its files from a page that needs a free account, under CC BY-SA 3.0. Download
the STEP file yourself, then:

```
ohs thirdparty om10 fetch --file ~/Downloads/om10-00001_20220701_va_01_3.stp
```

This asks you to accept the licence terms, verifies the file against the known hashes, copies it
unchanged into your user data directory (never into a source tree), applies the OM10 role preset
(names and roles only, no geometry) and imports it. Anything you derive from OM10 is an adaptation
under the same licence: OHS stamps its reports with the notice.

## 1. Read the train (lesson `train`)

```
ohs lesson show train --project om10.hsproj
ohs kinematics om10.hsproj --expect M4=1
```

OM10 is a 3.5 Hz (25,200 vph) movement with its small seconds at nine o'clock: the check asserts
that the mobile with the small-seconds wheel turns once a minute. Do the exercise:

```
ohs lesson check train --project om10.hsproj --answer 840
```

## 2. See how it keeps time (lesson `timegrapher`)

```
ohs lesson show timegrapher --project om10.hsproj
ohs timekeeping om10.hsproj
ohs timegrapher om10.hsproj --duration 30s
```

If you have a timegrapher and a built kit, write your readings down and calibrate the friction:

```
ohs bench calibrate om10.hsproj readings.csv -o om10-calibre.toml
```

From here add `--calibre om10-calibre.toml` to every command.

## 3. Choose a modification

The lessons cover the five modifications most people try first:

| Modification | Lesson | What to look at |
| --- | --- | --- |
| A different hairspring or balance | `hairspring` | rate, isochronism |
| A different mainspring | `mainspring` | amplitude, power reserve |
| Escape wheel and lever geometry | `escapement` | energy per beat, isochronism |
| Jewelling | `jewelling` | interference, plate stress |
| Skeletonising the gear bridge | `skeletonise` | mass, safety factor under shock |

Say you want a lighter balance with a longer power reserve. Read `hairspring` and `mainspring`,
then write the study:

```toml
[study]
name = "lighter balance, stronger spring"

[[change]]
parameter = "balance_inertia_mgcm2"
scale = 0.95

[[change]]
parameter = "barrel_torque_nmm"
scale = 1.05
```

```
ohs whatif om10.hsproj study.toml --verify --calibre om10-calibre.toml
```

You get both designs side by side: amplitude at three states of wind, rate, isochronism,
positional spread, power reserve and energy efficiency, a sentence on the cause of each change,
and the detailed model's check that the reduced model can be trusted for both designs.

## 4. Check it holds (structure)

```
ohs fea om10.hsproj --part "third wheel"
ohs fea om10.hsproj --part "train bridge" --case shock --g 5000 --size 0.2
```

A stronger spring raises the load on every tooth: re-check the weakest wheel and the bridge.
Lesson `skeletonise` shows the method for taking metal off a bridge.

## 5. Check it can be made

```
ohs tolerance om10.hsproj --tolerances my-machines.toml
ohs dfm om10.hsproj --process mill,wheel-cutting --rules my-rules.toml
ohs collisions om10.hsproj
```

Put your own tolerances and your own cutters in the files, and the verdicts become yours.

## 6. Report, and make a part

```
ohs report om10.hsproj -o om10-study --calibre om10-calibre.toml
ohs draw om10.hsproj --part "escape wheel" -o escape-wheel.pdf
```

The report summarises everything above with a pass, warning or fail for each section. The drawing
is dimensioned and at a standard scale: take it to the machine.
