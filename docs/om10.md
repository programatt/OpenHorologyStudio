# Tutorial: an OM10 modification study

This walks through a complete study on the open-source
[openmovement OM10](https://openmovement.org/) using only OHS and its lessons: read the movement,
see how it keeps time, change one thing, check that it still works and can be made.

!!! warning "About the numbers"
    The OM10 files are not in this repository. The numbers below were produced by running these
    commands on `om10-00001_20220701_va_01_3.stp`. The geometry results (parts, gear teeth, the
    train, the drawing) come from the file itself. The timekeeping results use a **reference
    calibre, not OM10's measured one**: the STEP file has no mainspring torque, balance inertia or
    hairspring data, so amplitude and power reserve are illustrative until you calibrate against
    your own timegrapher readings (section 2).

!!! info "What OHS finds in the OM10 file"
    166 parts, named by part number (`OM10-00150:1`), not by function. The file's dial axis is Y,
    which `ohs import` finds from the geometry and stores in the project. The gear train is read
    from the geometry: a 75-tooth centre wheel, 72-tooth third and 84-tooth fourth wheels, pinions
    of 16, 10, 9 and 8 teeth, and a 20-tooth escape wheel. Two things the geometry cannot tell are
    in the OM10 preset (`data/thirdparty/om10/rig.toml`): which part is the escape wheel, and that
    the barrel (whose 63-tooth ring does not match the centre pinion's involute closely enough to
    be found as a mesh) drives the centre pinion. The preset rules are marked as inferred there.

## 0. Get the movement

openmovement serves its files from a page that needs a free account, under CC BY-SA 3.0. Download
the STEP file yourself, then:

```
ohs thirdparty om10 fetch --file ~/Downloads/om10-00001_20220701_va_01_3.stp
```

This asks you to accept the licence terms, verifies the file against the known hashes, copies it
unchanged into your user data directory (never into a source tree), applies the OM10 role preset
(names and roles only, no geometry) and imports it. Anything you derive from OM10 is an adaptation
under the same licence: OHS stamps its reports with the notice.

## 1. Read the train (lesson `train`)

```
ohs lesson show train --project om10.hsproj
ohs kinematics om10.hsproj
ohs kinematics om10.hsproj --expect M33=1
```

OM10 is a 3.5 Hz (25,200 vph) movement. The barrel turns once in 3.94 hours, the centre wheel once
an hour, and the fourth wheel (mobile `M33` in the project made from the file above; the mobile
numbers can differ for you, so read them from `ohs kinematics`) once a minute: the check asserts
that. The escape wheel has 20 teeth, so one turn is 40 beats. Do the exercise:

```
ohs lesson check train --project om10.hsproj --answer 630
```

## 2. See how it keeps time (lesson `timegrapher`)

```
ohs lesson show timegrapher --project om10.hsproj
ohs timekeeping om10.hsproj
ohs timegrapher om10.hsproj --duration 30s
```

If you have a timegrapher and a built kit, write your readings down and calibrate the friction:

```
ohs bench calibrate om10.hsproj readings.csv -o om10-calibre.toml
```

From here add `--calibre om10-calibre.toml` to every command.

## 3. Choose a modification

The lessons cover the five modifications most people try first:

| Modification | Lesson | What to look at |
| --- | --- | --- |
| A different hairspring or balance | `hairspring` | rate, isochronism |
| A different mainspring | `mainspring` | amplitude, power reserve |
| Escape wheel and lever geometry | `escapement` | energy per beat, isochronism |
| Jewelling | `jewelling` | interference, plate stress |
| Skeletonising the gear bridge | `skeletonise` | mass, safety factor under shock |

Say you want a lighter balance with a longer power reserve. Read `hairspring` and `mainspring`,
then write the study:

```toml
[study]
name = "lighter balance, stronger spring"

[[change]]
parameter = "balance_inertia_mgcm2"
scale = 0.95

[[change]]
parameter = "barrel_torque_nmm"
scale = 1.05
```

```
ohs whatif om10.hsproj study.toml --verify --calibre om10-calibre.toml
```

You get both designs side by side: amplitude at three states of wind, rate, isochronism,
positional spread, power reserve and energy efficiency, a sentence on the cause of each change,
and the detailed model's check that the reduced model can be trusted for both designs.

## 4. Check it holds (structure)

```
ohs fea om10.hsproj --part OM10-00150:1
ohs fea om10.hsproj --part OM10-00184:1 --case shock --g 5000 --size 0.5
```

The first is the 75-tooth centre wheel: its Lewis stress is 6.4 MPa and the finite-element root
stress 18 MPa (the fillet concentrates it), safety factor 19 for brass. The second is a plate with
the 5000 g end shake on it. Only round pivot and screw holes are held fixed: a window or slot is
left free, as in the real part. A stronger spring raises the load on every tooth, so re-check
the weakest wheel and the plate. Lesson `skeletonise` shows the method for taking metal off a bridge.

## 5. Check it can be made

```
ohs tolerance om10.hsproj --tolerances my-machines.toml
ohs dfm om10.hsproj --process mill,wheel-cutting --rules my-rules.toml
ohs collisions om10.hsproj
```

Put your own tolerances and your own cutters in the files, and the verdicts become yours.

On the OM10 with the default `mill,wheel-cutting` processes, `dfm` reports many errors: the
module-0.11 wheels need a cutter the default list does not have, and the 7-tooth pinions are below
the 8 teeth the process cuts. That is the rule set talking, not a fault in the movement; put your
own cutters in. `collisions` sweeps the train and the parts around it, but it treats everything
outside the gear train as stationary, so the pallet fork and its jewels show up as overlaps with
the escape wheel. Read those pairs as the escapement working, not as collisions.

## 6. Report, and make a part

```
ohs report om10.hsproj -o om10-study --calibre om10-calibre.toml
ohs draw om10.hsproj --part OM10-00150:1 -o centre-wheel.pdf
ohs gear --teeth 75 --module 0.11 --bore 0.6 --thickness 0.2 --step-out wheel.step --dxf wheel.dxf --profile-only
```

The report summarises everything above with a pass, warning or fail for each section. The drawing
is dimensioned and at a standard scale: take it to the machine.
